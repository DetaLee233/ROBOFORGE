# ROBOFORGE · 机甲工坊

浏览器 3D 机甲对战游戏（类 Robocraft）：用零件自由拼装载具，然后在 **5v5 PVE** 战场中作战。

> **在线试玩：[https://detalee233.github.io/ROBOFORGE/](https://detalee233.github.io/ROBOFORGE/)**

基于 Three.js（r128，CDN 全局引入）。**无构建步骤、无打包器、无 ES 模块**——全部是经典 `<script>`，按顺序由 `index.html` 加载。

---

## 特性

- **拼装编辑器**：方块 / 强化装甲 / 车轮 / 履带 / 机械腿 / 旋翼 + 武器 + 功能模块；多格占位（3×3×3）、垂直安装（`dir`）、对称建造、按键分组、点数预算（2000）。
- **5v5 PVE**：敌方舰队从载具库随机匹配（按点数接近、避免与玩家同款、保持多样）。
- **两种对局模式**：
  - **团队死斗**：消灭全部敌军获胜。
  - **夺点模式**：3 个镜像对称得分点 + 对角双基地；占领累积“结束进度”（20 分钟倒计时，时间到比进度）；占满 3 点解除对方基地护盾并给对方机体强化；可攻击暴露的基地八面体倒扣进度；阵亡 10 秒后在基地复活；基地护盾半径内以 20 倍工程射线自动治疗友军。
- **武器**：机枪、榴弹炮（曲射/火炮式，视弹道计算机而定）、充能射线炮（蓄力穿透光束）、工程激光（持续射线，伤敌 64/发、疗友 120/发，射速按把线性叠加）。
- **能量系统**：载具共享武器能量池 + 备用能源模块。
- **物理与 AI**：贴地行驶 / 全向移动 / 飞行；AI 保持交战距离、规避来袭弹道、利用掩体、优先打击关键部位、夺点模式机动占点/回基地修复。
- **设置**：反转鼠标/转向、灵敏度、**按键映射自定义**（为触屏/手柄适配预留）。

## 操作

| 操作 | 默认按键 |
| --- | --- |
| 前进 / 后退 | `W` / `S` |
| 左移·左转 / 右移·右转 | `A` / `D` |
| 升空·跳跃 / 下降·助跑跳 | `空格` / `左Shift` |
| 开火 / 蓄力 | 鼠标左键 |
| 开镜（第一人称） | 鼠标右键 |
| 切换武器组 | `1` `2` `3` |
| 镜头远近 | 鼠标滚轮 |
| 暂停菜单（含自毁机体、设置、重开、返回） | `Esc` |

> 所有按键均可在「设置 → 操作按键」中重新绑定。

## 本地运行

直接用浏览器打开 `index.html` 即可（`file://` 可用，但 three.js 走 CDN 需要联网）。
也可以用任意静态服务器托管本目录，例如：

```bash
# Python 3
python -m http.server 8080
# 然后访问 http://localhost:8080/
```

## 技术栈

- Three.js r128（CDN 全局）
- 纯原生 JavaScript（经典脚本，无模块/无依赖/无构建）
- WebAudio 程序化音效
- Canvas 2D 生成载具缩略图

## 目录结构

```
index.html            入口：按顺序加载 three.js 与全部脚本
css/style.css
js/main.js            应用引导：渲染器 / 输入 / 屏幕切换 / 主循环
js/core/              事件总线、工具、全局 Config、设置、材质、音效、输入、轨道相机
js/parts/             零件（方块/强化/车轮/履带/机械腿/旋翼/机枪/榴弹/射线炮/工程激光/计算机/电池）
js/vehicle/           蓝图、载具库、载具运行时（物理/伤害/开火）、抛射体
js/world/arena.js     对称地形、掩体、空气墙、出生点
js/ai/aiController.js AI 驾驶与射击
js/game/              对局模式（死斗 / 夺点）、护盾、得分点、对局管理器
js/ui/                机库、编辑器、载具库、缩略图、HUD、设置面板
```
